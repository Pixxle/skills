### Worktree cleanup

**You own every byte you delete. The gates below are the review.** Reclaim local disk by pruning merged or abandoned git worktrees and stale iOS simulators.

1. **Snapshot and audit.** Record `df -h /`, then run [`scripts/worktree-audit.sh`](../scripts/worktree-audit.sh) `[-b <pr-base-ref>] [repo-path]` ([`principle-build-the-lever`](../../principle-build-the-lever/SKILL.md)). The script lives in cortex's skill directory. Run it from inside the target repo, or pass that repo as `repo-path`, since it audits the repo it runs in. Without `-b` it checks `MERGED` against `origin/HEAD`, so pass `-b origin/<branch>` when PRs target another branch. It reads paths from `git worktree list`, never hand-typed, since a hand-typed `myrepo-worktrees/x` misses one that lives at `.claude/worktrees/x` ([`principle-encode-lessons-in-structure`](../../principle-encode-lessons-in-structure/SKILL.md)). It classifies each worktree by size, age, merge state, uncommitted work, PR state, and the newest Claude Code or Codex chat that touched it, then suggests a bucket. The transcript scan is slow, so run it in the background. The script only reads. Deletion stays in this playbook.
2. **The bucket is advice, not permission.** The pinned and active chats are the real artifact ([`principle-prove-it-works`](../../principle-prove-it-works/SKILL.md)). Get that set from the user or the runtime's session list and cross-check every candidate. The audit has marked `safe` a worktree the user had pinned, so the pinned set wins.
3. **Verify usage before deleting.** For every `verify-recent-chat` row, or anything you doubt, spawn subagents in parallel to read the transcripts and report whether the chat is pinned or ongoing and which worktrees it touches ([`principle-guard-the-context-window`](../../principle-guard-the-context-window/SKILL.md), since transcripts are bulk). `LAST_CHAT` names the runtime. Claude Code keeps transcripts under `~/.claude/projects/<slug>/`, one slug per worktree path. Codex keeps them under `${CODEX_HOME:-~/.codex}/sessions/`, with the session's working directory in each file. A pinned chat spawns [`arena`](../../arena/SKILL.md) and repro trees into sibling worktrees via background subagents, and those are in use even when their names never reach the session list. Pick each subagent's model for the job per [cortex's Subagents section](../SKILL.md#subagents).
4. **Pause on irreversible loss.** `wip:N` is N tracked uncommitted edits. Show the diff and get a decision first, since removing a clean worktree is recoverable from its branch but uncommitted work is gone. `scratch:N` is untracked throwaway, safe to drop, but name the files. Deletion is on the Always-pause list in [`principles`](../../principles/SKILL.md#autonomy), and a full-autonomy grant does not lift it. Present the confirmed set (path, size, bucket, and why it is not in use) with the step 6 targets, and get the user's go-ahead before step 5. Clean, merged, and not-in-use rows can go as one batch. `wip` and in-use rows each need their own decision.
5. **Prune the confirmed set.** Per path, `git worktree remove --force <path>`. If the dir survives on ignored build artifacts, `rm -rf` it, then `git worktree prune`. A `missing` row needs only `git worktree prune`. Branch refs survive, so no commits are lost. Confirm with `df -h /` and a rerun of the audit.
6. **Simulators and other reclaimers.** Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, and package caches (pnpm, uv, brew, yarn). Deleting these also needs the user's go-ahead, so list them with their sizes in the step 4 confirmation. Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in use by which chat, or uncommitted work).
