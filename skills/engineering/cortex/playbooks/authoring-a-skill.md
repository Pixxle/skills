### Authoring a skill

**You own the skill's voice and structure for this collection.**

1. Read and follow [`write-a-skill`](../../../productivity/write-a-skill/SKILL.md).
2. Enforce collection rules: folder name matches frontmatter `name`; frontmatter is only `name` + `description`; capability-term tool language; relative resource paths; register in `.claude-plugin/plugin.json` and the bucket README; re-run `scripts/link-skills.sh`.
3. When in doubt, delete. Keep only prose that changes a decision. Delegate to siblings by path — don't restate them.
4. Run **Opening a PR**.

**Reply:** skill path, key design choices, registration/link notes.
