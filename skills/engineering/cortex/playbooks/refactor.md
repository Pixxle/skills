### Refactor

**You own investigation and proposals. Implement only what the user accepts.**

1. Read and follow [`thermo-nuclear-refactor`](../../thermo-nuclear-refactor/SKILL.md), including its investigation brief.
2. When the user wants a maintainability pass on a change without a full proposal loop, use [`thermo-nuclear-code-quality-review`](../../thermo-nuclear-code-quality-review/SKILL.md) instead or first.
3. Preserve observable behavior. Split bug fixes and intentional behavior changes out for explicit acceptance (**Feature** or **Bug fix**).
4. After accepted implementation, run **Opening a PR**.

**Reply:** coverage, proposals (accepted/rejected), what changed, how you proved behavior held.
