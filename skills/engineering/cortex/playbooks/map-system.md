### Map system

**You own a cited onboarding map, not a refactor backlog.**

1. Read and follow [`create-system-map`](../../create-system-map/SKILL.md). Prefer hierarchical subagent exploration for large systems. Keep summaries in the main thread. One question or one subsystem answered in chat is [Investigation](investigation.md), not this.
2. Describe the implemented design. Do not turn the map into an audit or proposal list unless the user asks. Then rematch [Refactor](refactor.md) or [Swarm](swarm.md).
3. Skip [Opening a PR](opening-a-pr.md) unless the user asked to commit the map artifacts.

**Reply:** map root path, what the system does, how to navigate the docs, open unknowns.
