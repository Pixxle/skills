### Worktree and simulator cleanup

1. Snapshot and audit. Record `df -h /`, then run [`scripts/worktree-audit.sh`](../scripts/worktree-audit.sh) `[-b <pr-base-ref>] [repo-path]` in the background, since its transcript scan is slow ([Build the Lever](../../principles/build-the-lever.md)). Pass `-b origin/<branch>` when PRs target a branch other than the remote default.
2. The `BUCKET` column is advice, not permission. Get the pinned and active chats from the user or the sidebar, and cross-check every candidate against them ([Prove It Works](../../principles/prove-it-works.md)). The pinned set wins. The lever has marked `safe` a worktree the user had pinned.
3. Verify usage before deleting. For every `verify-recent-chat` row, and any row you doubt, read and follow [`swarm`](../../swarm/SKILL.md) to fan out workers that read the transcripts. Run them locally, since the transcripts live only on this machine. Each reports whether its chat is ongoing and which worktrees it touches ([Guard the Context Window](../../principles/guard-the-context-window.md)). Check each against step 2's pinned set. A pinned chat spawns arena and repro trees into sibling worktrees via background subagents, and those are in use even when their names never hit the sidebar.
4. Pause on irreversible loss. A `clean` row that is merged, or whose PR is merged or closed, and is not in use, proceeds without asking, since its branch keeps the commits. Every other row waits for the user's decision, shown with its evidence: the diff for `wip:N`, the file list for `scratch:N` (untracked files, which `--force` deletes), the PR for `hold-open-pr`, and the unmerged commits for `review`. A `detached` row with `MERGED` at `no` loses its commits on removal, so it always pauses.
5. Prune the confirmed set. For each confirmed path, copied from the audit table, run `git worktree remove <path>`. Add `--force` only to a row the user approved dropping, so git refuses any dirty tree nobody approved. Then run `git worktree prune`, which also clears `missing` rows. Confirm with `df -h /` and re-list.
6. Simulators and other reclaimers. Simulators are usually the next-biggest win. Hold them while a kept chat is running simulator tests. Otherwise run `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, and package caches (pnpm, uv, brew, yarn). Clear only caches the user has not said to keep.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in use by which chat, or uncommitted work).
