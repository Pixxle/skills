### Shipping

**You own what lands. Read and follow [`shipping`](../../shipping/SKILL.md) in full before step 1.** Each step below is the skill's step of the same number. A ship request authorizes merging the verified run and the `--force-with-lease` pushes that move each next PR onto trunk in skill step 4. Every other write on the Always-pause list in cortex's Autonomy section still needs the operator.

1. **Resolve the forge, then get a non-author verdict on each PR.** Resolve it per **Forge** (step 4) in [`playbooks/opening-a-pr.md`](opening-a-pr.md).
2. **Find the contiguous verified run and its ceiling.**
3. **Re-check each older verdict by `git patch-id` against the current head.**
4. **Land bottom-up, one PR at a time.**
5. **Leave the stack alone while it lands.** On GitHub, watch the run with the skill's step 5 watcher call, by absolute path from the target repo's checkout with `--owner` and `--repo`.
6. **Stop at the ceiling.**

**Reply:** the skill's reply shape, plus the forge you used and any fallback.
