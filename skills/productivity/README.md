# Productivity

Daily non-code workflow tools.

- [grill-me](grill-me/SKILL.md) — interview you relentlessly about a plan or design until you reach shared understanding, resolving each branch of the decision tree.
- [teach](teach/SKILL.md) — teach a concept using a workspace-local mission, resources, and learning records.
- [write-a-skill](write-a-skill/SKILL.md) — create new agent skills with proper structure, progressive disclosure, and bundled resources.
- [write-rfc](write-rfc/SKILL.md) — turn a conversation into a concise RFC in Simplified Technical English, with explicit decisions and comparative trade-offs for alternatives.
